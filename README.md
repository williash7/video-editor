# עורך וידאו

אפליקציית אנדרואיד לעריכת סרטונים **על הטלפון בלבד** — בלי להעלות את הסרטון לשום מקום ובלי טוקנים.

- תמלול בעברית בלי אינטרנט (whisper.cpp, מודל ivrit.ai)
- חיתוך בפקודות טקסט: `תחתוך מ-1:20 עד 3:45`
- רשימת חיתוכים להוצאת קטעים מיותרים, והסרת שתיקות אוטומטית
- שורטים אנכיים 9:16 עם כתוביות צרובות, עורך כתוביות ועיצוב
- פיצול סרטון ארוך לחלקים
